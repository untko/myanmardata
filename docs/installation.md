# Installation

## Stable release

To install myanmardata, run this command in your terminal:

```sh
uv add myanmardata
```

Or if you prefer to use `pip`:

```sh
pip install myanmardata
```

## From source

The source files for myanmardata can be downloaded from the [Github repo](https://github.com/untko/myanmardata).

You can either clone the public repository:

```sh
git clone https://github.com/untko/myanmardata
```

Or download the [tarball](https://github.com/untko/myanmardata/tarball/main):

```sh
curl -OJL https://github.com/untko/myanmardata/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd myanmardata
uv sync
```
